## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Three Stores** | Access your Epic Games, GOG, and Amazon Prime Gaming libraries |
| **Linux & Mac** | Full support via Wine and Proton for playing Windows-only games |
| **No Bloat** | Lightweight alternative to the official launchers with better performance |
| **Import Existing** | Import already-installed games without re-downloading them |
